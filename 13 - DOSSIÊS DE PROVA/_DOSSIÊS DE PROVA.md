# Dossiês de Prova

Esta pasta é o **material de estudo diário** do vault 2027. Ela não substitui as notas das pastas 01–09 — essas continuam sendo a **fonte**. O dossiê é a camada de conversão entre *saber o assunto* e *julgar um item sob pressão*.

Cada dossiê tem seis seções:

| Seção | O que é | De onde vem |
|---|---|---|
| **1. Pontos de corte** | As distinções que a banca já testou | Itens reais + seus erros |
| **2. Proposições-âncora** | Verdades curtas em forma de item CERTO | Fonte + gabaritos |
| **3. Armadilhas** | Como a banca constrói o item ERRADO neste tópico | Itens reais |
| **4. Itens reais** | Todos os itens de prova do tópico, com gabarito | `itens_classificados.csv` |
| **5. Esqueleto discursivo** | Roteiro de 60 linhas para a 2ª fase | Fonte |
| **6. Fonte** | Link para a nota-ensaio | Vault |

Ver [[Estratégia 2027 — Estudo Orientado à Prova]] para o método completo.
